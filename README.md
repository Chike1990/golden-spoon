# Golden Spoon Cuisine

Food ordering, loyalty rewards and event bookings for Golden Spoon Cuisine, Awka — *"Whatever the problem, chop first."*

**Stack:** React 19 + Vite, Express 5, PostgreSQL, Drizzle, TypeScript, Docker, Terraform, AWS

## Structure

- `apps/web` — React 19 + Vite customer and admin front end
- `apps/api` — Express 5 + Drizzle REST API
- `packages/shared` — types, validation schemas and money helpers shared across apps
- `infra` — Terraform definitions for AWS infrastructure
- `design-reference` — Figma Make prototype, visual reference only
- `docs` — seed data, budget config and project notes
